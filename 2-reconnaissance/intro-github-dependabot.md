# Introduction to GitHub Dependabot

[GitHub Dependabot](https://github.com/VanessaTsang888/foundational-javascript-security/security) allows us to evaluate our dependencies for free and provides some alerts when there are some issues.

## Instructions

How to use the tool.

1. select a repo (project) in our GitHub.
2. To enable Dependabot for this repo is navigate to top-right menu 'Security' and on this page you need to Enable the Dependabot alerts option by click on the grey btn on the right of that option. This will monitor the dependencies and will notify us when one or more of the dependencies need our attention. I am already using this on my 'your diet goals' repo.
3. Now Enable all all the options using the grey 'Enable' btn on the right of each options.

The biggest issue with an application is we don't control the code of the dependencies. This is why in my projects I try not to install too many dependencies where possible this is could create open issues in my apps.

### Sub-dependencies

Some dependencies or packages uses other packages i.e. react sripts uses many other packages inside of its own package. Therefore its really useful to have these reports from Dependabot since it helps us understand what's happening deep inside of our app and everything we are using and how we can resolve any issues down the road or open issues for our app and our users.
