# Challenge and Solution

What is secure deserialization?

## Solution

Deserialization is the transformation of data coming from a file or the network typically from a JSON or XML format into an object that your app can read.

Insecure Deserialization is when a cyber criminal exploit untrusted data to render the apps resources usless, i.e. a Denial of Service Attack, or even execute code inside of our app. Therefore, securing this process is crucial to protect our users.

### Summary

1. Transformation of data from one state to another.
2. Cyber criminals exploit untrusted data to render our app useless.
