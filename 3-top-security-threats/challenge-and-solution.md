# The Chanllenge and The Solution

The Challenge:
<br>What is the best resource for top threats?

The Solution:
<br> [The OWASP official website](https://owasp.org/#) contains the latest and greatest info about security threats. The page on the [Top 10 Threats](https://owasp.org/www-project-top-ten/) more info on each issue and even contain code snippets on how to resolve the issue.

## A06:2021-Vulnerable and Outdated Components

During my work within Defensive Programming I have been using the [A06:2021-Vulnerable and Outdated Components](https://owasp.org/Top10/A06_2021-Vulnerable_and_Outdated_Components/#example-attack-scenarios) resource and that has help me keep a number of websites and web applications safe from cyber criminals. An example is on the [BCC Design System project](https://design.bristol.gov.uk/) where I had completed the 'Resolve Security Vulnerabilities' ticket by upgrading various outdated dependancies and tested my work on my feature branch and on the development branch. During my testing stage I had also tested for regression to see if my upgrade of the Docusaurus framework had caused any problems with features on the website.
